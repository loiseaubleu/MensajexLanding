# Mensajex Landing

Landing de Mensajex, un asistente para pequeños negocios que permite atender consultas a cualquier hora y controlar qué números telefónicos pueden comunicarse con ellos. El proyecto original se trabajó en abril de 2025.

## Créditos y mi aporte

Participé como **asistente de desarrollo frontend**. Implementé la landing desde cero en Astro a partir de las ideas de diseño y las secuencias de animación que me compartía Henry29. Trabajé con la paleta y los lineamientos visuales definidos por su diseñador gráfico.

Henry29 lideró la revisión de las animaciones del robot en Lottie. Las revisamos juntos y yo integré las secuencias en la página. Esta versión también recoge mi refactor posterior de la estructura de la landing, los estilos responsivos y la reproducción de las demos.

La marca, los logos y las animaciones se presentan como parte del proyecto Mensajex. La atribución del código se conserva en el archivo [LICENSE](LICENSE).

## Ejecutar en local

En la terminal de VS Code, desde la carpeta del proyecto:

```powershell
npm.cmd ci
npm.cmd run dev
```

Abre [localhost:4321](http://localhost:4321) o la dirección que indique Astro. Para generar la versión de producción, ejecuta `npm.cmd run build`.
